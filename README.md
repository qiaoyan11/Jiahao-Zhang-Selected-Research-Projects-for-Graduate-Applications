For the detailed competition description and explanation of the project, please refer to the report in each folder. 

## Project 1: Adaptive Graph Encoding Optimization for Large Language Models: 
Machine Learning with Graphs Project, supervised by Prof. Qiaoyu Tan
### Task:  
Reproduced and optimized the ICML-nominated paper 'Large Language and Graph Assistant'  
Improved graph feature extraction using a Random Walk-based template and a multi-head self-attention projector.This boosted PubMed node classification accuracy to 94.83% and quadrupled the speed of large graph tasks.  
### reference:
https://github.com/VITA-Group/LLaGA.git 

## Project 2: Data Science Capstone Project-Rate My Professor Analysis: 
Data Science Capstone Project, Supervised by Prof. Pascal Wallisch
### Task: 
Designed a data-driven analytical framework and executed statistical tests, regression models, and classification models to examine key determinants of instructor ratings in the Rate My Professor dataset.

## Project 3: Kaggle Image Matching Challenge 2025
Kaggle Competition - Top 7% (out of 943 teams)
### Task:  
Estimate relative camera poses and reconstruct consistent 3D scenes from large-scale and unstructured imageset. Designed a complete 3D reconstruction pipeline (DINOv2, LightGlue, COLMAP) and proposed key optimizations, including CLIP-based retrieval, refined two-stage feature matching, and advanced geometric consistency checks.

## Project 4: NYU Shanghai Machine Learning Competition-Representation Learning and Image Classification
Machine Learning Competition: Supervised by Prof. Shengjie Wang
### Task： 
Built a convolutional autoencoder with residual blocks to learn compact and expressive latent representations from Pokémon Fusion images, enabling high-quality reconstruction and downstream classification and achieve 5th place on the leaderboard. Designed a combined logarithmic MSE–cross-entropy loss and a lightweight classification head to stabilize training and improve linear probing performance across 170 Pokémon types.
